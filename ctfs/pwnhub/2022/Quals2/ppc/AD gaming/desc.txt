description
小 X 在某比赛中一路过关斩将，来到了最后一轮，与对手 1v1 对决。
比赛按照攻防比赛的模式进行，有多道题目供选手挑战。选手可以合理安排自己的时间，对每道题目都可以选择开发
攻击脚本攻击对方，或者修复自己的题目使其免遭对方的攻击。若在某一轮 Tx 一位选手完成了攻击脚本的开发，而
在另一轮 Ty 另一位选手才完成题目的修复，(Tx < Ty)，则第一位选手可以获得 Ty - Tx 的攻击分数（每轮 1
 分）。如果比赛结束时另一位选手仍未完成题目的修复，则第一位选手可持续获得分数至比赛结束。如果另一位选手
 在第一位选手完成攻击脚本开发前修复了题目，则第一位选手无法从本道题目中获得攻击分数。
有一位先知想帮助小 X 赢得本场比赛的胜利，偷偷地告诉了小 X 对手在本场比赛中的做题策略。你能帮助小 X 安
排好做题顺序，使得小 X在本次比赛中尽可能多的领先对手么？
假定每一轮一位选手只能同时做一件事（一道题目的攻击脚本开发或者修复二选一），攻击脚本开发和题目修复均在
完成后的下一轮才开始发挥效果。每道题有且仅有一个漏洞，每位选手的攻击脚本和修复工作都是有效的。
Time Limit: 5000MS
Memory Limit: 256MB
input
第一行为两个整数 N、T (1 <= N <= 10, 1 <= T <= 300)，表示该场比赛一共有 N 道题目，比赛时间总共持续 T 轮。组内接下来 N 行，每行四个整数 Ai、Bi、Ci、Di ，其中
Ai 表示小 X 对于题目 i 完成攻击脚本开发所需的轮数，-1 表示小 X 在比赛中写不出这道题的攻击脚本。
Bi 表示小 X 对于题目 i 完成修复工作所需的轮数，-1 表示小 X 在比赛中不会修这道题。
Ci 表示对手将于Ci (0 <= Ci < T)轮完成题目 i 的攻击脚本开发工作，-1 表示对手在比赛中写不出这道题攻击脚本。
Di 表示对手将于Di (0 <= Di < T)轮完成题目 i 的修复工作，-1 表示对手在比赛中不会修这道题。
output
输出仅有一行，包含一个整数 S，表示在小 X 优势最大的情况下，自己和对手的攻击分数之差。
Sample Input1
2 8
2 1 3 5
1 2 3 5
Sample Output1
3
